# Purzelhuus Menüplaner – korrigierte Version

Diese Version behebt die automatische Wochenplan-Erstellung.

Wichtig für GitHub Pages:
- ZIP entpacken
- Einzelne Dateien hochladen, nicht die ZIP-Datei
- index.html, menus.js, sw.js, manifest.webmanifest und icon.svg müssen direkt im Hauptverzeichnis liegen
- Nach dem Upload auf dem iPhone die App einmal neu laden oder vom Home-Bildschirm löschen und neu hinzufügen

Funktionen:
- Neue Woche automatisch vorschlagen
- Dropdowns pro Tag
- Qualitätskontrolle
- neue Menüs direkt erfassen
- Export/Import
